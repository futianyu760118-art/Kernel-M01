# M01 简单操作说明

## 一、当前默认设置

第一家接入单位：**恒剑光电**。

管理员和总经理：**朱剑军**。

系统内部仍保留编号，普通使用者不需要记住这些编号：

| 对外显示 | 系统内部编号 | 说明 |
|---|---|---|
| 恒剑光电 | `TENANT_A` | 第一家接入单位 |
| 朱剑军 | `P_OWNER` | 管理员、总经理、总控负责人 |
| 总控智能体 | `A_MASTER_KERNEL` | M01 唯一总控智能体 |

## 二、第一次打开系统

打开：`http://192.168.0.71:3101/`

演示环境只需要两步：

1. 点击“**一键登录**”。系统会自动登录并启用总控智能体。
2. 在“快速办理”中选择人员和事项，点击“**一键办理**”。

办理后，对话框下方会直接显示“审批状态”和“办理结果”。例如离职会显示“等待审批 / 尚未办理”，不会误认为已经完成。

左侧“系统导航”可以直接进入“办理中心、审批中心、人员名单、操作记录”。高风险事项提交后，进入“审批中心”点击“批准”或“拒绝”；批准后系统会继续办理，拒绝后人员保持原状态。

确认页面显示：单位是“恒剑光电”，管理员是“朱剑军”，总控状态是“在线”。

正式环境点击“使用企业账号登录”，登录后仍按“选择人员 → 一键办理”操作。

## 三、人员名单怎么处理

系统启动时会从 EBMS 读取原有人员名单，显示在“人员名单和状态”中。系统只读取：

- 姓名；
- 部门；
- 岗位；
- 原系统账号是否能够对应。

系统**不会读取或复制 EBMS 的旧密码**。

人员状态的简单含义：

| 页面显示 | 含义 |
|---|---|
| 正常 | 当前可以按岗位使用系统 |
| 待确认 | 人员资料还需要管理员确认 |
| 已离职 | 已停止使用权限 |
| 已撤销 | 管理员主动收回了权限 |

重名、没有账号、岗位不清楚的人员会进入“待复核”，不能自动获得更高权限。

## 四、管理员日常操作

### 1. 一键办理人员

在“快速办理”中选择人员和事项：

- 入职：直接办理普通员工入职；
- 调整到经理岗位：直接办理调岗；
- 办理离职：自动进入审批，不能直接删除权限。

### 2. 查看人员

点击“刷新人员名单”，上面的主名单只显示在职人员。离职人员单独放在“已离职人员”中，默认收起，需要查询交接记录时再展开。

选择某位人员后，可以在“人员配备清单”中查看岗位权限、智能助手、电脑手机等设备和办公物品的状态。现有系统没有设备台账的项目显示“待登记”，离职人员显示“待核对归还”。

### 3. 查看权限

在“人员编号”中填写人员的内部编号，点击“查看这个人的权限”。页面会用中文显示岗位和权限；带“需要审批”的权限不能直接执行。

### 4. 办理入职或调岗

选择人员后，点击“办理入职并绑定岗位”或“调整到经理岗”。人员变更会写入操作记录。

### 5. 办理离职或撤权

离职、撤销人员权限、数据导出和设备操作都属于高风险操作。系统会要求审批，不能只靠前端按钮直接完成。

### 6. 查看记录

点击“查看操作记录”，可以复查登录、人员变更、权限判断、审批和智能体操作。

## 五、智能体接入 HUB

在 HUB 中按以下顺序操作：

```text
登录 HUB
→ AI 港湾
→ 智能体目录
→ 找到要接入的智能体
→ 点击“接入 M01”
```

接入成功后，在 M01 的“智能体状态”中应看到智能体、负责人、权限范围和“正常”状态。

如果负责人离职或被撤权，名下智能体会一起停止工作。

## 六、系统异常时先看什么

1. 页面右上角是否显示“在线”。
2. 点击“刷新系统状态”。
3. 查看“人员名单和状态”是否有人员。
4. 查看“智能体状态”是否为“正常”。
5. 点击“查看操作记录”确认最近一次失败原因。

Docker 管理员可执行：

```powershell
docker ps --filter "name=aeos-m01"
Invoke-RestMethod http://192.168.0.71:3101/health
Invoke-RestMethod http://192.168.0.71:3101/readyz
```

## 七、重启后检查

```powershell
docker restart aeos-m01-kernel
Invoke-RestMethod http://192.168.0.71:3101/readyz
```

重启后应保持：朱剑军仍是管理员和总经理；恒剑光电人员名单仍然存在；总控智能体仍然在线；HUB 接入的智能体仍然存在；操作记录没有丢失。

## 八、正式环境提醒

当前 Docker 演示环境用于验证流程。正式上线前必须配置企业账号登录、HTTPS、正式密钥和备份恢复。演示访问密码不能用于公网。
