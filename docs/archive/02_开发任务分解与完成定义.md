## 演示现状与生产工作包区别
- 可复用：零依赖 Node.js 演示 API、M07/M13 HMAC 示例、POMS 能力查询、授权决策逻辑、3 个测试。
- 必须重构：内存数据、默认共享管理员 Token、开发密钥、无 OIDC、无持久化、无 M02 Outbox、审批 501、有限 ABAC、无分布式撤权。
- 禁止将 DEMO 直接发布公网；禁止凭单一管理令牌替代用户身份；禁止相信浏览器传递的 `principal_id`。

## Definition of Done
1. PR + Code Review + 静态扫描、安全测试通过。
2. API/Event/Result/Evidence 版本登记，所有身份及对象归属无冲突。
3. 正负测试、跨租户及撤权测试在 CI 通过；追踪 ID 进入审计。
4. 证据包（环境、版本、日志、截图、报告、操作者和时间）归档；Owner/Gate 签批。
5. 可回滚，回滚验证成功，安全问题无未关闭 P0/P1。
