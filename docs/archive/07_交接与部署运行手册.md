# M01 DEV 演示交接与部署运行手册

## 环境
- Node.js >= 20；无 npm 运行时第三方依赖。
- Windows：解压后运行 `start_windows.bat`；手动：`npm test && npm start`。
- Docker：复制 `.env.example` 为 `.env`，替换所有密钥后运行 `docker compose up --build`。
- 页面 `http://localhost:3101`；健康检查 `GET /health`。

## 使用约束
- 演示版 `M01_ADMIN_TOKEN=local-demo-admin` 不应在公网或共享网络环境使用。
- 演示程序监听 0.0.0.0；如仅本机验证，应在 Windows 防火墙/容器网络中限制非本机访问；生产部署须重构认证后方可开放。
- `.env`、真实 Token、用户个人数据不得提交仓库、报告或测试证据包。
- 演示内存存储，重启失去操作数据；不可用于真实授权和财务/设备控制。
