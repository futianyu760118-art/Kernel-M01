## 2. 主要接口候选（并非现网事实）
| 接口 | 方法/路径 | 方向 | 鉴权 | 主要字段 |
|---|---|---|---|---|
| 人事事件 | POST /integrations/m07 | M07→M01 | HMAC-SHA256 | event_id,tenant_id,type,person_id,position_id |
| Agent 注册撤销 | POST /integrations/m13 | M13→M01 | 独立 HMAC-SHA256 | event_id,tenant_id,type,agent_id,owner_person_id,parent_agent_id,scopes |
| 个人能力 | POST /kernel/v1/capabilities | POMS→M01 | MVP 管理服务令牌（正式须 JWT） | principal_id |
| 授权决策 | POST /kernel/v1/authorize | 各服务→M01 | 同上 | tenant_id,principal_id,resource,action |
| 强制撤权 | POST /kernel/v1/revocations | 管理员→M01 | 同上 | principal_id,reason |

**对接红线**：在生产版中，`principal_id` 必须从已验证的用户/服务身份及服务端上下文推导，不能直接采信请求 Body；Webhook 需 mTLS/短期凭据、时间戳、nonce、签名、重放窗、来源网络限制与轮换。

## 3. 联调 7 个步骤
1. 各系统 Owner 共同冻结源码 commit、部署域、真实路径、请求鉴权和对象 ID 方案。
2. M07：从入职→岗位变更→离职发出真实事件；M01 存储、版本化和确认，观测重复投递/乱序处理。
3. POMS：通过用户 Token 查询能力，展示仅获准的操作；直接调用被隐藏业务接口必须仍被拒绝。
4. M13：向 M01 注册人员所属 Agent、子 Agent、工具清单与授权时效；验证子 Agent 不继承父 Agent 未授权权限。
5. 执行时：POMS/M13 业务服务先请求 Guard；拒绝或需审批不得执行目标动作。
6. 离职/调岗后：撤销旧岗位、所有关联 Agent 访问及会话，在节点和缓存上观测生效。
7. M02：追踪操作、判权、撤权与事件投递证据；M12 完成安全 Gate。

## 5. 重要边界
